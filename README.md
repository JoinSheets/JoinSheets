# JoinSheets

**English** · [Русский](README.ru.md)

![version](https://img.shields.io/badge/version-0.1.0b1-blue)
![license](https://img.shields.io/badge/license-Apache--2.0-green)
![status](https://img.shields.io/badge/status-beta-yellow)

A browser-only table builder: join flat data sources, compute fields (renames,
collision resolution, formulas), and export to Excel/CSV. No server, no install --
download the repository and open `index.html`.

Ships with a ready-to-try demo ([`sample-data/`](sample-data/)) so there's something
to click through with no setup. The optional [JoinSheetsImport](https://github.com/JoinSheets/JoinSheetsImport)
submodule adds an "Import from Excel" button for turning a spreadsheet into a source.
