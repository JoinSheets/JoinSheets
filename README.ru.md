# JoinSheets

[English](README.md) · **Русский**

![version](https://img.shields.io/badge/version-0.1.0b1-blue)
![license](https://img.shields.io/badge/license-Apache--2.0-green)
![status](https://img.shields.io/badge/status-beta-yellow)

Конструктор таблиц, работающий целиком в браузере: объединяет плоские источники
данных, считает показатели (переименование, разрешение коллизий, формулы) и
выгружает результат в Excel/CSV. Без сервера, без установки — скачай репозиторий и
открой `index.html`.

В комплекте готовый демо-набор ([`sample-data/`](sample-data/)) — можно сразу
попробовать, без настройки. Опциональный submodule
[JoinSheetsImport](https://github.com/JoinSheets/JoinSheetsImport) добавляет кнопку
«Импорт из Excel» для превращения таблицы в источник данных.
